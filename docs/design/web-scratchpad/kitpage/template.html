The AgentOS V2 kit

Every element and every line of CSS on a V2 screen comes from these 25 components. Screens can only pick from them, and every prop is a token name or a variant listed in the ledger, each with its reason. This page is built from ledger.json and the real /kit sheet, in your current theme.

Vocabularies

The five value sets props draw from

A gap, a width, a colour or a glyph is never a raw value: it is one of these names. Stylelint and the ledger both refuse anything else.

Assessment

How flexible it is

Closed on purpose

  • No className, style or size props anywhere. A screen can't invent a look.
  • Lengths go through Space (11 steps) and Width (12), colour through Tone (7) and MarkKind (8).
  • The largest components, Button and Row, stop at 8 props, the budget's ceiling.
  • Status is one form per state: a ticket's state always looks the same, whichever screen draws it.

Open where content goes

  • slot props take any content (children, Page.middle/side/action, Head.summary, Row.more, Table.foot…). Variety comes from composing, not from options.
  • Stack and Text together lay out and set type for anything the bigger pieces don't cover.
  • Row's five kinds (line, item, tile, rack, band) cover every list shape in V1 plus All teams' board.
  • Badge's six kinds replace six separate V1 chip components.

Where it will be stretched next

  • No form inputs: no text field, textarea, checkbox or form row. The search field is inside Page, and the composer inside Thread. New ticket (W4) and Settings (W8–W9) need them.
  • No toast, tooltip or popover of its own. Hover text is the native title.
  • Menu lives only on the rail, and Dialog, Select, Segmented and Tabs have one user each. Each names the ticket that brings its second.
  • The budget is full at 25 of 25. A new component needs a raises entry from the owner, or a merge of two existing ones.
