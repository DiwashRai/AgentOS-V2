Building blocks, and whether to add more

From a read of all 52 feature files at 090db35. The kit is about right. Most of what repeats across screens is ordinary composition, which belongs in features/shared and costs nothing against the budget. One new kit component pays for itself.

Add Section 41st slot · worth it

A named <section> with an h2, an optional count or note, an optional end slot (faces, an Edit button) and its body. About 5 props.

  • Replaces 8 hand-built heading blocks, 3 of them with their own local definitions: library side panel, peek, ticket Plan and Talk, Workflow tab, library panel, All teams.
  • Settles owner decision #1. The peek's Dialog would lay out Sections instead of styling whatever top elements it gets.
  • Gives the peek's and the rail's regions names in the accessibility tree. No screen can name them today.
  • Cost: about 50 kit lines. It needs two raises entries: components to 41, lines to about 7,680.
  • Cheaper alternative: a sections list prop on Dialog's side look. That ends decision #1 with no new slot, but leaves the 8 heading sites as they are.

Three small kit fixes no new slot

  • An Icon down. Today one chevron means both "fold open" and "move down" in the same row (content.tsx:31,64, nav.tsx:64).
  • Row takes an empty cell. That removes the <Text>{""}</Text> placeholders in RunsTab.tsx:190,207,235.
  • Drop Stack justify="between". No screen uses it.

Shared pieces in features no kit cost

  • Loading and missing blocks. They cover 15 loading and 12 error sites, and "Can't reach the server" is written out 4 times. The peek's loading state is plain text without the status role the other screens give it.
  • Promote the library's NameCell. Its pattern (a name with quiet words after it) appears 4 times.
  • One face helper. 13 call sites each pick the colour seed by hand, so an agent could get a person's hue.
  • One "time ago". 4 formatters read "47m ago", "3h 05m" and "just now" on different screens.
  • Others: usePeek(), "N shipped this week", the key-hint foot, the Plan section and the "Every stage gets" strip. Each is copied 2 or 3 times.
  • Together these save about 120–150 lines and remove the inconsistencies above.

Watch, don't split yet

  • Chip is at the 8-prop cap and has three roles. The agent-state pill has one caller. If another pill need comes, move that case out instead of adding a ninth prop.
  • Card is at 8 of 8, with three looks. Stage uses 6 props, agent and ticket 3 or 4. A StageCard split is the natural one, but not with 4 call sites.
  • Row's band and columns kinds exist only for the All teams board. That's fine while there is one board.
  • Compare appears on none of these screens. It shows only in a version conflict, which the fixtures don't stage; the kit sheet has it.

Not worth adding

Glyph plus words, key hints, a plan section, a ticket header and a drift badge would each be a composition of existing pieces. Putting them in the kit would spend budget the owner wants kept for real behaviour, which is the same rule as the accepted budget review.
