  content }. Page used to switch to a narrow rail when it found a FormRow

  in any sidebar changed the page.
- Head's unused "rack" level is now "line": a plain line of a list with its

  built themselves, so their fold says whether it is open.
- Stack's unused five columns are now two, for a form's settings side by side
  that fall to one column when narrow; a stage's settings use it.
- Field has a search form (the glyph, Esc to clear), so the workflow editor's
  library search looks and behaves like the page's.

  loop bands, turns it off), so AGENTS.md's blocks drop the empty Stack that
  made room for them.
