# flat: the fixes to make this round

Flat came second in the bracket. It lost to warm 1–3, beat precise and colour only on the twins tie-break, and beat the current screens 4–0. The judges like how light and dense it is. It loses because busy screens run together. Fix these, staying flat (tone and space first, a hairline where structure needs one, no shadows except on floating surfaces):

1. **Separate the sections on the busy screens** (My queue, Intake, the ticket's Runs tab) without putting them on cards:
   - give each group clearly more space and a heavier heading above it, and a step of tone or a hairline between groups;
   - on Intake, make each query read as its own block, and give the failed query a danger-tinted state.
2. **Give the lists structure:**
   - a labelled column header row on Compact and Intake, with stage, source, priority, status and assignee in aligned columns, so Intake is no longer a two-line list;
   - faint row dividers, or a tighter rhythm, where rows float (Intake, Skills), so each row's meta sits near its title.
3. **Use state colour where it carries meaning:**
   - running and queued agent cards look different;
   - the header's running and queued counts carry their glyphs;
   - the failed query stands out.
4. **Give floating surfaces an edge.** Popovers and menus get a hairline and a soft shadow; on the light theme they currently read as inline panels.
5. **Give editable properties a quiet resting chip surface:** owner, assignee, runtime, model, effort.
6. **Fix the alignment.** The expanded run card on Runs and Compact's expanded row stick out about 10px past the content column. Line them up, with proper inner padding.
7. **Clip nothing under Compact's footer** ("Waiting on others", NW-24).
8. **Keep what wins:** the lightness, the density, Save as the clear primary, and "Request changes" as a real button (round 3 lost partly by stripping its button look).

The judges' full notes follow.
