# warm: the fixes to make this round

Warm won the bracket. It beat flat 3–1 and colour 3–1, beat precise on the twins tie-break, and beat the current screens 4–0. It wins because each group sits on its own sheet, so busy screens break into units you can scan. It loses votes for heaviness. Fix these, keeping the warmth and the grouping:

1. **No nested cards.** Use one surface level per area, with spacing and hairlines inside it:
   - the ticket page currently stacks page card, stage card, builder card and run card;
   - the document modal frames its content twice.
2. **Density:**
   - cut the page gutter, the card padding, the gaps between cards (about 24px down to 12px) and the row height, so Compact fits everything ("Waiting on others", NW-24) and the ticket's plan isn't clipped;
   - put the column header row back on Compact;
   - stop titles truncating.
3. **Make Save a real primary button.** It currently looks disabled next to Discard.
4. **Give the sections hierarchy and state:**
   - not every section should be the same white card;
   - put Agents at work in the same system as the other sections;
   - mark state on the agent cards: running tinted, queued quieter (dashed or muted);
   - state colour on the header counts.
5. **Make it less bubbly:** smaller radii (about 8–10px), and lighter row-title weight.
6. **Give selected chips contrast,** with an accent tint rather than white on off-white.
7. **Give the keyboard-hint footer a surface** so it doesn't float on the background.
8. **Raise the contrast between the paper and the cards** in light mode.

The judges' full notes follow.
